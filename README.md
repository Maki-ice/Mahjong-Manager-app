# Mahjong Manager App

麻雀の対局開始、プレイヤー登録、点数表示、和了点計算の基礎ロジックを実装した Next.js 製のWebアプリです。

就職活動で「学習した技術を使って、身近な課題をWebアプリとして形にした経験」を説明するためのポートフォリオとして作成しています。

## 概要

友人同士の麻雀対局で、紙やメモアプリに頼らず点数を管理できることを目指したアプリです。現在はMVPとして、4人対局の作成、ローカル保存、点数ボード表示、和了点計算ロジックとテストを実装しています。

## 主な機能

- 4人分のプレイヤー名を入力して対局を作成
- ブラウザの localStorage に対局データを保存
- 東南西北の位置関係を意識した点数ボード表示
- 翻・符・親子・ロン/ツモ・本場を考慮した和了点計算
- Vitest による点数計算と局進行ロジックの単体テスト

## 使用技術

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vitest
- Docker / Docker Compose

## 工夫した点

- UIだけでなく、麻雀の点数計算や局進行を `lib` 配下の関数として分離し、テストしやすい構成にしました。
- まず localStorage を使った小さなMVPにして、データ永続化や認証を後から拡張しやすい形にしています。
- Docker Compose を用意し、環境差分を減らして起動できるようにしています。

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開きます。

Dockerを使う場合:

```bash
docker compose up --build
```

## テスト

```bash
npm test
```
